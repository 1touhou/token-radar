Token Launch Radar

Protocols that record no token, ranked by what their token would be worth if it launched on the record as it stands — and what to do to farm each one before it does.

How an implied value is worked out

implied value = TVL × 0.25 × growth × maturity × breadth

  • growth = 1 + clamp(7-day TVL change, −60%, +120%) ÷ 100 × 0.5
  • maturity = 0.6 + min(age in days, 1095) ÷ 1095 × 0.4 (age unknown: 365 days)
  • breadth = 1 + 0.05 × min(chains − 1, 4), at most 1.20

Every row uses the same formula and no name is special-cased. A protocol is shown as pre-token because its record carries no token — never as proof that it has none.
